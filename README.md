</details>

<details>
<summary>📦 Installation</summary>

1. Download the repo Zip:
   https://github.com/dev-salik/my-chatbot.git

2. Install Dependencies

3. API Key
   ENTER YOUR API KEY=your_generated_api_key

4. Run
   python main.py
